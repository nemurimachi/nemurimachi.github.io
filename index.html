ショート動画投稿ツール

Nemurimachi が自身の公式アカウントへの投稿作業を自動化するために使用している、個人用のソフトウェアです。

目的

毎週決まった曜日にショート動画を投稿するにあたり、手作業で行っていた アップロードと公開日時の設定を自動化するために作られました。 一般に配布・提供しているサービスではなく、Nemurimachi 本人以外が利用することはありません。

機能

  • 手元のフォルダにある動画と投稿文を読み込む
  • 投稿しない曜日を避けて、投稿日を自動で割り当てる
  • YouTube へアップロードし、指定時刻に公開されるよう予約する
  • Instagram へ指定時刻に投稿する

利用している API

  • YouTube Data API v3 — 自身のチャンネルへの動画アップロードと公開日時の設定
  • Instagram Platform API — 自身のアカウントへの動画投稿

いずれも Nemurimachi 本人が管理するアカウントに対してのみ使用します。 第三者のアカウントやデータを扱うことはありません。
