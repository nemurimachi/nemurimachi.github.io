利用規約

ショート動画投稿ツール（Nemurimachi-shorts） ／ 最終更新日: 2026年10月6日

1. 適用範囲

本規約は、Nemurimachi が開発し、Nemurimachi 自身のみが利用するソフトウェア 「Nemurimachi-shorts」（以下「本ツール」）の利用条件を定めるものです。

本ツールは一般に配布・販売・提供されていません。本人以外の利用者は存在せず、 第三者がインストールまたは利用することはできません。

2. 本ツールの目的

本ツールは、Nemurimachi 自身が制作した動画を、Nemurimachi 自身が管理する YouTube チャンネルおよび Instagram アカウントへ投稿し、公開日時を設定するために 使用されます。それ以外の目的には使用しません。

3. YouTube API Services の利用

本ツールは YouTube API Services を利用しています。 本ツールの利用者は、 YouTube 利用規約 に同意するものとします。

Google による情報の取り扱いについては、 Google プライバシー ポリシー をご確認ください。

本ツールが使用する権限は https://www.googleapis.com/auth/youtube.upload のみ、 呼び出す API メソッドは videos.insert のみです。

4. 禁止事項

本ツールは、次の行為には使用しません。

  • 第三者のアカウントまたはデータへのアクセス
  • 取得したデータの第三者への提供、販売、共有
  • 広告配信、アクセス解析、機械学習モデルの学習への利用
  • YouTube API サービス利用規約および YouTube デベロッパー ポリシーに反する一切の行為

5. データの取り扱い

本ツールが取り扱うデータの範囲、保存場所、削除方法については プライバシーポリシー に定めるとおりです。

6. 料金

本ツールは無償であり、販売、ライセンス供与、広告掲載のいずれも行いません。 本ツールから収益は発生しません。

7. 免責

本ツールは現状有姿で提供され、動作の完全性や継続性について保証しません。 本ツールの利用により生じた損害について、開発者は責任を負いません。

8. 本規約の変更

内容を変更する場合は、本ページを更新し、冒頭の最終更新日を改めます。
