ショート動画投稿ツール（Nemurimachi-shorts） ／ 最終更新日: 2026年10月6日

このツールについて

本ツールは、Nemurimachi が自身の公式アカウントへショート動画を投稿する作業を 自動化するために、Nemurimachi が個人的に利用しているソフトウェアです。 一般に配布・提供しているサービスではなく、Nemurimachi 本人以外が利用することはありません。

YouTube API Services の利用について

本ツールは YouTube API Services を利用しています。

本ツールを利用することで、利用者は YouTube 利用規約 に同意したことになります。

Google がどのように情報を取り扱うかについては、 Google プライバシー ポリシー をご確認ください。

本ツールが使用する YouTube Data API の権限は、次の1つのみです。

https://www.googleapis.com/auth/youtube.upload

この権限は、Nemurimachi 自身が管理する YouTube チャンネルへ動画をアップロードし、 公開日時を設定する目的にのみ使用します。他の目的には一切使用しません。 呼び出す API メソッドは videos.insert のみです。

取得する情報

本ツールは、利用者から個人情報を収集しません。 一般の方が本ツールを利用する場面はなく、第三者の情報を取得、保存、送信することは一切ありません。

本ツールが扱うのは、次のものに限られます。

  • Nemurimachi 本人が投稿するために用意した動画ファイルと投稿文
  • Nemurimachi 本人のアカウントに対する認証トークン

保存場所と第三者提供

取得した認証情報は、Nemurimachi 本人が管理するパソコンのローカル領域にのみ保存されます。 外部のサーバーへ送信すること、第三者へ提供・販売・共有することはありません。 広告、分析、機械学習モデルの学習には一切使用しません。 サーバー、データベース、アクセス解析のいずれも保有していません。

本ツールによる Google ユーザーデータの取り扱いは、 Google API サービスのユーザーデータに関するポリシー （Limited Use の要件を含む）に準拠します。

データの削除とアクセスの取り消し

本ツールが保存するのは認証トークンのみです。以下の方法でいつでも削除・無効化できます。

  • Google アカウントからアクセス権を取り消す — https://security.google.com/settings/security/permissions を開き、本ツールを選択してアクセス権を削除します。これにより保存済みのトークンは即座に無効になります。
  • ローカルの認証情報ファイルを削除する — 本人のパソコン上にある認証情報ファイルを削除します。

本ツールは Google ユーザーデータを保管するサーバーを持たないため、 削除の対象となるデータはローカルの認証トークンのみです。

Instagram について

本ツールは Instagram のコンテンツ公開 API も利用し、Nemurimachi 自身のアカウントへ動画を投稿します。 取り扱いの方針は上記と同じで、第三者の情報は扱いません。
