ショート動画投稿ツール ／ 最終更新日: 2026年10月5日

このツールについて

本ツールは、Nemurimachi が自身の公式アカウントへショート動画を投稿する作業を 自動化するために、Nemurimachi が個人的に利用しているソフトウェアです。 一般に配布・提供しているサービスではなく、Nemurimachi 本人以外が利用することはありません。

取得する情報

本ツールは、利用者から個人情報を収集しません。 一般の方が本ツールを利用する場面はなく、第三者の情報を取得、保存、送信することは一切ありません。

本ツールが扱うのは、次のものに限られます。

  • Nemurimachi 本人が投稿するために用意した動画ファイルと投稿文
  • Nemurimachi 本人のアカウントに対する認証トークン

Google ユーザーデータの取り扱い

本ツールは YouTube Data API v3 を利用し、次の権限を使用します。

https://www.googleapis.com/auth/youtube.upload

この権限は、Nemurimachi 自身が管理する YouTube チャンネルへ動画をアップロードし、 公開日時を設定する目的にのみ使用します。他の目的には一切使用しません。

取得した認証情報は、Nemurimachi 本人が管理するパソコンのローカル領域にのみ保存されます。 外部のサーバーへ送信すること、第三者へ提供・販売・共有することはありません。 広告、分析、機械学習モデルの学習には一切使用しません。

本ツールによる Google ユーザーデータの取り扱いは、 Google API サービスのユーザーデータに関するポリシー （Limited Use の要件を含む）に準拠します。

Instagram について

本ツールは Instagram のコンテンツ公開 API も利用し、Nemurimachi 自身のアカウントへ動画を投稿します。 取り扱いの方針は上記と同じで、第三者の情報は扱いません。

データの削除について

本ツールが保存するのは認証トークンのみです。 Nemurimachi 本人がローカルの認証情報ファイルを削除すること、および各プラットフォームの 設定画面からアクセス権を取り消すことで、いつでも削除・無効化できます。

本ポリシーの変更

内容を変更する場合は、本ページを更新します。

お問い合わせ
